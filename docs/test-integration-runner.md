# API integration runner

From the repository root, `corepack pnpm test:integration` builds contracts under the project heavy-job queue, then snapshots the sorted API `*.integration.test.ts` files. A clean run creates up to twelve UUID-named disposable loopback PostgreSQL databases and separate temporary directories by default, bounded by available CPUs; partial runs create no more slots than selected files. `GRAPHQL_INTEGRATION_SHARDS=1..12` can lower or raise the limit for a specific machine. Each slot runs one file at a time with one Vitest worker. The startup test runs once, alone before the parallel phase, because it starts the local development command and uses shared checkout build output.

The runner prints one bounded PASS or FAIL line per file and continues through every file after a failure or a skipped case. After a default full sweep, it automatically reruns each failed file once on fresh disposable databases, printing separate RETEST PASS or RETEST FAIL lines and a retest summary. The original full-run file and case counts remain unchanged, and any first-pass failure keeps the command nonzero even if its retest passes. Failed file output is saved under ignored `.logs/test-integration/<run-id>/`; retest failures are saved in its `retest/` subdirectory. If a child exits without a summary, the runner reports that explicitly. Interrupts and the outer job timeout stop new dispatch, signal owned child process groups, escalate to SIGKILL after a bounded grace period, wait for them to exit, then drop only databases created by this run.

An explicit `TEST_DATABASE_URL` selects one serial slot and must name a loopback test database. The runner does not create or drop that database, so automatic fresh-database retesting is disabled for this mode; rerun failures manually on a fresh test database. To resume from a file, use `GRAPHQL_INTEGRATION_START_AT=apps/api/test/<name>.integration.test.ts corepack pnpm test:integration`. To rerun only failures from a completed runner log, use `GRAPHQL_INTEGRATION_FAILED_LOG=/path/to/log corepack pnpm test:integration`. Each selected path must match a discovered file. Resume and failed-file retests are partial evidence; run the command again without either setting to verify the full suite.
